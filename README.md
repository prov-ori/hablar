# ¡Hablar! — интерактивная платформа для изучения испанского

Веб-приложение без сборки и зависимостей: откройте `index.html` в браузере — и можно учиться.
Весь прогресс хранится локально в браузере (есть экспорт/импорт в JSON).

## Что внутри

| Раздел | Содержание |
|---|---|
| 🗺️ **Курс** | 27 тем (A1–B1), 784 слова, 141 урок. Упражнения 9 типов: выбор перевода, аудирование, ввод с клавиатуры, диктант, пары, сборка фразы, пропуски, перевод предложений. Ошибки возвращаются в конце урока. |
| 🧠 **Повторение** | Интервальное повторение карточек (упрощённый SM-2). Слова попадают в колоду после уроков или из словаря. |
| ⚙️ **Глаголы** | 74 глагола, 7 времён (presente, indefinido, imperfecto, perfecto, futuro, condicional, subjuntivo). Таблицы спряжения генерируются движком и подсвечивают неправильные формы; тренажёр с настройками. |
| 📐 **Грамматика** | 23 темы с объяснениями на русском, кликабельными примерами и тестами. |
| 📖 **Чтение** | 10 рассказов A1–B1: перевод слов по нажатию, перевод предложений, озвучка всего текста, вопросы на понимание. |
| 💬 **Диалоги** | 8 ролевых ситуаций (кафе, гостиница, врач, аренда квартиры…) с объяснением, почему неверный ответ не подходит. |
| 🎮 **Игры** | Контрольное время, мемори, ¿el o la?, верно/неверно, виселица, анаграммы, числа, часы, диктант, произношение (распознавание речи), столицы. |
| 🌎 **Культура** | 21 испаноязычная страна, 30 идиом с дословным переводом, заметки об обычаях. |
| 🏆 **Профиль** | XP и уровни, серия дней, цель дня, тепловая карта активности, 25 достижений. |

Озвучка — через Web Speech API браузера (лучше всего в Chrome/Edge/Safari). Для ввода испанских символов есть
экранная панель и сочетания Alt + a/e/i/o/u/n → á é í ó ú ñ.

## Запуск

```bash
# просто открыть файл
xdg-open index.html            # или двойной клик

# или через локальный сервер
python3 -m http.server 8000    # → http://localhost:8000
```

Для публикации подходит GitHub Pages (Settings → Pages → ветка, корень репозитория).

## Структура

```
index.html            точка входа, порядок подключения скриптов
css/style.css         стили, светлая/тёмная тема, мобильная вёрстка
js/util.js            DOM-хелпер, проверка ответов, числа и время по-испански
js/store.js           прогресс, XP, серия, SRS, достижения (localStorage)
js/speech.js          синтез/распознавание речи, звуки
js/ui.js              тосты, модалки, конфетти, поле ввода с á é ñ
js/exercises.js       генерация и отрисовка упражнений
js/data/*.js          контент: словарь, глаголы, грамматика, рассказы, диалоги, культура
js/views/*.js         экраны
tests/                модульные и браузерные тесты
```

Добавить тему словаря — дописать объект в `TOPICS_RAW` (`js/data/vocab.js`): уроки, игры и словарь подхватят её автоматически.
Новый глагол — строка в `VERBS` (`js/data/verbs.js`) с пометками чередования (`sc`), особой формы `yo`, основы претерита (`pret`) и будущего (`fut`).

## Тесты

```bash
node tests/unit.test.js                         # спряжения (эталонные таблицы), числа, время, целостность данных
NODE_PATH=$(npm root -g) node tests/smoke.test.js   # браузерный прогон всех экранов (нужен playwright)
```
