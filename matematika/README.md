# Аксиома — математика с нуля до гимназии

Статический сайт без сборки и зависимостей: откройте `index.html` в браузере (или через любой статический хостинг).
Прогресс хранится в браузере (localStorage), его можно выгрузить и загрузить файлом на странице «Мой прогресс».

## Что внутри

| Раздел | Содержание |
|---|---|
| Курсы | 8 курсов по структуре эстонской программы, 79 уроков: I «Числа и счёт» (1–3 кл.), II «Арифметика и дроби» (4–6), III «Алгебра» (7–9), IV «Геометрия» (7–9), V «Уравнения и функции» (10), VI «Тригонометрия и векторы», VII «Начала анализа», VIII «Вероятность и пространство» (11–12). В каждом уроке — формулы (KaTeX), таблица главного, вопросы, карточки и эстонские термины. |
| Задачник | 90 генераторов задач (включая тренажёр эстонских терминов), по 3 уровня, проверка ответа (дроби, корни, π, несколько корней), разбор, режим «Спринт 60 с», смешанная тренировка и «Разминка дня». |
| Лаборатория | 17 интерактивных моделей: умножение-прямоугольник, числовая прямая, дроби-пиццы, прямая, парабола, система уравнений, квадраты Пифагора, тригонометрия треугольника, конструктор графиков, показательная и логарифм, единичная окружность (с перетаскиванием), синусоида, векторы, касательная, суммы Римана, кубики и закон больших чисел, кредитный калькулятор. |
| Контрольные | 8 контрольных (96 заданий) по образцу экзаменов с полными решениями и самооценкой. |
| Тренажёры | Карточки (Лейтнер), пробный экзамен, блиц, «Формула и смысл», «Узнай по свойству», история математики. |
| Справочники | Словарь из 90 терминов (рус. — эст.), 29 математиков, лента истории. |

## Честность источников

Тексты, вопросы и задачи составлены автоматически (ИИ), а не учителем и не Harno. Структура следует
государственной программе (põhikooli ja gümnaasiumi riiklik õppekava). Каждый урок помечен:
«Программа» (обязательная тема), «Программа +» (с дополнениями), «Сверх программы» (расширенный курс).
Контрольные — по образцу экзаменов, не официальные задания.

## Файлы

```
index.html          оболочка, мета-теги и превью для соцсетей
config.js           настройки (названия, курсы, звания, подписи тренажёров)
c1.js … c8.js       уроки курсов I–VIII
drills.js           генераторы задач (gen(уровень, R) → задача)
labs.js             интерактивные лаборатории (canvas/SVG)
extra.js            словарь, пары формул, «узнай по свойству», математики, «О платформе»
tests.js            контрольные
engine.js           движок SPA (роутинг, уроки, квизы, карточки, задачник, лаборатории, прогресс)
styles.css          стили, светлая и тёмная темы
katex/              KaTeX 0.19 (формулы работают без интернета)
```

Инструменты разработки лежат в `../tools/matematika/` (не нужны для работы сайта):

```bash
node tools/matematika/validate.js matematika          # схема, формулы (KaTeX), прогон всех генераторов
PW_CHROME=/opt/pw-browsers/chromium python3 tools/matematika/e2e.py matematika --shots /tmp/shots
python3 tools/matematika/make_brand.py tools/matematika/spec.json matematika   # иконки и og-image
python3 tools/matematika/check_meta.py matematika
```

`validate.js` генерирует по 150 задач на каждый уровень каждого генератора и проверяет, что собственный
ответ генератора принимается проверкой, а заведомо неверный — нет; все формулы компилируются KaTeX в строгом режиме.

## Публикация

Сайт рассчитан на адрес `https://prov-ori.github.io/hablar/matematika/` (GitHub Pages из ветки `main`, корень репозитория).
После слияния ветки: Settings → Pages → Deploy from a branch → `main` / `(root)`. Если адрес другой — поменяйте
`base_url` в `tools/matematika/spec.json` и перезапустите `scaffold.py` и `make_brand.py`, чтобы ссылки превью совпали.
