# Кортекс — строение мозга: 3D-атлас и интерактивный курс

Статический сайт без сборки: откройте `index.html` (или любой статический хостинг, например GitHub Pages). Прогресс хранится в браузере.

## Что внутри

| Раздел | Содержание |
|---|---|
| **3D-атлас** (`#/lab/brain3d`) | Модель мозга по данным МРТ: 34 области коры × 2 полушария, таламус, базальные ганглии, гиппокамп, миндалина, мозжечок, ствол, желудочки, мозолистое тело. Вращение и зум, наведение и выбор любой структуры, карточка с описанием и клиникой, окраска по долям, извилинам и функциям, прозрачность коры, «разбор» на части, срез плоскостью с настоящим МРТ-снимком, режим теста («найди на модели», «назови подсвеченное»). |
| **МРТ-атлас** (`#/lab/mri`) | Три плоскости T1-снимка с цветными метками структур; щёлкните точку — атлас назовёт её (координаты MNI). |
| **Курсы** | 5 курсов, 20 уроков (общий план, кора, глубокие структуры, мозжечок и ствол, клетки и сети); в уроки встроены сокращённые версии 3D-атласа. |
| **Контрольные** | 5 контрольных, 62 вопроса с образцами ответов и самооценкой. |
| **Тренажёры** | Карточки (Лейтнер), экзамен, блиц, «Структура и функция», «Узнай по описанию», история нейронауки. |
| **Справочники** | 60 терминов, 24 учёных, лента истории. |

## Откуда геометрия

Все данные открыты и упакованы в pip-пакеты `nilearn` и `atlasreader`:

- **кора** — поверхность `fsaverage5` (FreeSurfer, усреднённая по МРТ-данным людей), подразделена (Loop) до ≈ 82 тыс. граней на полушарие; нормали, глубина борозд (`sulc`) и область атласа Desikan–Killiany приписаны каждой вершине;
- **подкорка, мозжечок, ствол, желудочки, мозолистое тело** — маски `aparc+aseg` (FreeSurfer, MNI152, 1 мм) → сглаживание → marching cubes → прореживание → сглаживание Тюки;
- **МРТ** — шаблон MNI152 T1 (1 мм), ресемплированный в сетку атласа.

Это «средний» мозг, а не снимок конкретного человека; цвет, влажный блеск и сосудистый рисунок на коре добавлены шейдером. Мелкие структуры (например, гипоталамус) в атласе объединены в «вентральный диэнцефалон».

Пересборка данных:

```bash
pip install nilearn atlasreader nibabel numpy scipy scikit-image trimesh fast-simplification
python3 tools/mozg/build_brain.py        # → mozg/brain-mesh.js, mozg/brain-vol.js
```
